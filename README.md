# IChan conecta ESG 🌱

> Projeto acadêmico desenvolvido para a turma de primeiro semestre do curso de **Análise e Desenvolvimento de Sistemas** da **Faculdade de Tecnologia e Inovação Senac-DF**.

---

## 🎯 Sobre o Projeto
O **IChan conecta ESG** é uma plataforma web voltada exclusivamente para a realidade do **Distrito Federal (DF)**. O objetivo principal é conectar demandas reais da comunidade (registradas por cidadãos nas Regiões Administrativas) a empresas que buscam aplicar os **7 pilares ESG** na prática com transparência socioambiental.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído estritamente com tecnologias fundamentais de desenvolvimento web, priorizando a didática e a facilidade de explicação:
* **HTML5** (Estruturação semântica das páginas)
* **CSS3** (Estilização limpa, responsiva e moderna)
* **Git & GitHub** (Controle de versão e armazenamento em nuvem)

---

## 📂 Estrutura de Arquivos e Páginas
O sistema é composto por 4 páginas principais interligadas e um arquivo de estilos centralizado:

```text
conecta-esg-final/
